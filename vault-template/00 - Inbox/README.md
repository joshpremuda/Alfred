# Inbox

**The rule:** Everything new comes here first. Process weekly.

When processing, move each item to:
- `10 - Projects/` — if it belongs to an active project
- `20 - Ideas/` — if it's an idea worth keeping
- `30 - Areas/` — if it's an ongoing responsibility
- `40 - Resources/` — if it's reference material
- `50 - Archive/` — if it's done or inactive
- Delete — if it's not worth keeping

---

*Drop new notes here. Don't organize in the moment.*
